# recroll

Modern x64 reconnect plugin for Hearthstone Deck Tracker.

Repository: `hdt-reconnect`
Plugin/assembly: `recroll`

## Build
1. Open GitHub Actions.
2. Run **Build recroll x64**.
3. Download artifact **recroll-x64**.

## Install
1. Close HDT.
2. Put `recroll.dll` in the HDT plugins folder.
3. Start your custom HDT build as Administrator.
4. Enable `recroll`.
5. During a Hearthstone match click **RECROLL**.

## Logs
Search `hdt_log.txt` for `[recroll]`.
